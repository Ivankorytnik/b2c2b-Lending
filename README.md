# Свой АТОМ для работы в такси — B2C2B HTML-лендинг

Публичная ссылка: https://ivankorytnik.github.io/b2c2b-Lending/

Одностраничный адаптивный сайт для водителей, планирующих купить собственный электромобиль АТОМ. Поля город + телефон + обязательное согласие расположены непосредственно на первом экране и дублируются в нижнем блоке.

## Что реализовано

- 13 основных разделов по ТЗ, включая преимущества, покупку, аренду против владения, стоимость километра, ИП/самозанятых, характеристики, зарядку/сервис/гарантию, порядок покупки, 12 FAQ.
- Три интерактивных калькулятора, без сервера и сборки.
- Покупка: аннуитет, нулевая ставка, остаток задолженности на момент оценки; контроль допустимых значений.
- Аренда или собственность: отдельно ежемесячный денежный поток и полная стоимость периода с остаточной стоимостью авто и непогашенным долгом.
- Стоимость пробега: бензин, электричество, потери при зарядке, сравнение 100 км и эффект за год, столбчатые диаграммы.
- Верхняя и нижняя формы с маской телефона, выбором города (подсказки + возможность ввода собственного), проверкой согласия и ошибок.
- SEO, адаптивная верстка для мобильных устройств, UTM, события dataLayer и опциональная Яндекс Метрика.
- Официальное фото АТОМа с сайта производителя, визуальные элементы и ссылка на официальный источник.

## Важно: режим демонстрации

В `config.js` поле `leadEndpoint` равно `null`. Поэтому **заявки реально не отправляются**, а пользователи видят предупреждение. Нельзя считать лендинг готовым к боевому сбору лидов, пока не подключены защищённое серверное API и утверждённые юридические документы. `privacy.html` — **только демо-пояснение, не юридически утверждённая политика**.

## Включение приёма заявок

1. На российском сервере создайте защищённый POST API приёма, сохраняющий заявку и передающий её в ELMA CRM. Секретные ключи ELMA допускаются **только на сервере**.
2. На сервере добавьте валидацию, rate limiting, антиспам, дедупликацию по `idempotency_key`, журнал согласий, обработку отзыва согласия, корректный CORS с разрешённого домена.
3. Настройте `config.js`: `window.ATOM_CONFIG = { leadEndpoint: 'https://your-russian-host.example/api/leads', consentVersion: 'approved-version-id', metrikaCounter: null }`.
4. Контракт успеха: HTTP 2xx + JSON `{ "success": true, "lead_id": "..." }` или `{ "id": "..." }`. Только после этого интерфейс показывает «Заявка отправлена». При сетевой ошибке, таймауте или отсутствии ID успех не показывается.
5. Перед запуском замените демо-страницу `privacy.html` утверждёнными политикой и согласием оператора, укажите реквизиты и согласуйте использование фотографий производителя.
6. Настройте и проверьте Метрику. Телефоны и города не отправляются в аналитические события.

### Поля POST

`phone`, `city`, `source` (строго `ATOM_TAXI_B2C2B`), `lead_source`, `created_at`, `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `form_location` (`hero` или `bottom`), `consent_pd`, `consent_version`, `consent_timestamp`, `scenario`, `calculator`, `idempotency_key`.

Данные отправляются только по HTTPS. При повторе неопределённо завершившегося запроса используется прежний `idempotency_key`; сервер должен принимать повторный запрос идемпотентно.

## Проверка и размещение

Сайт статический: `index.html`, `config.js`, `privacy.html`, `favicon.svg` размещаются в корне репозитория. Внешнее изображение первого экрана зависит от доступности официального медиа-хостинга АТОМ. GitHub Pages размещает только статику, не работает как защищённый сервер приёма персональных данных.

Перед боевым запуском проверить на iOS/Android/Chrome, в том числе ширины 320, 390, 768, 1280 и 1920 px, работу форм, CORS и CRM, доступность картинок, SSL и юридические тексты.

**Примечание.** Сайт создан по предоставленному ТЗ. Это не копия исходников ChatGPT Site; действующий B2B-сайт https://b2b-atom.ru/ не изменён.
