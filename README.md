# АТОМ для работы в такси — лендинг B2C2B

Исходники демонстрационной версии. **Форма заявки размещена на первом экране**: справа на десктопе, сразу после заголовка на смартфоне. Кнопки в шапке, после калькулятора и внизу ведут к этой форме.

## Запуск

Это статический сайт. Откройте `index.html` или опубликуйте файлы `index.html` и `config.js` на своём веб-сервере / GitHub Pages.

## Настройка сбора заявок

По умолчанию заявка **НЕ отправляется**: в `config.js` `leadEndpoint: null`. На неподключённом лендинге показывается честное сообщение, что данные не отправлены.

До запуска необходимо:

1. Создать защищённый приёмщик заявок на российской инфраструктуре с серверной интеграцией в ELMA CRM. Публичная страница не должна содержать токенов ELMA.
2. Указать адрес HTTPS API-эндпоинта в `config.js`, например `leadEndpoint: 'https://ваш-домен.рф/api/leads'`. Приёмщик должен разрешать CORS для домена страницы и обрабатывать POST JSON.
3. Утвердить политику обработки персональных данных, указать оператора, заменить демо-текст в футере и ссылку «Подробнее» в форме на официальную политику.
4. Проверить тестовые заявки и mapping полей к ELMA, дубли, аудит, сохранение согласия, ошибки сети, защиту от спама и уведомления менеджеру.

### Формат POST JSON

- `phone`: `+79991234567` (обязательно)
- `city`: город работы (обязательно)
- `driver_status`: `self_employed` / `individual_entrepreneur` / `not_registered` / `not_selected`
- `consent_pd`: `true`
- `consent_marketing`: `true`/`false` (отдельное необязательное согласие)
- `scenario`: `rent`/`own`/`plan`/`not_selected`
- `lead_source`: `atom_taxi_owner_landing`
- `page_url`, `submitted_at`, `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`

Успех показывается **только при HTTP 2xx**. При ошибке введённые пользователем значения сохраняются, при отсутствии endpoint показывается сообщение без имитации отправки.

## Что учтено

- Минимальная верхняя форма: телефон, город, необязательный статус, отдельные согласия на ПДн и рекламу.
- Адаптивная сетка с формой в hero на мобильных.
- Якорные CTA в `#apply`, закреплённая мобильная CTA вне зоны формы.
- Валидация телефона и города, состояние загрузки, защита от ложного сообщения об успехе.
- Передача UTM и выбранного сценария при наличии CRM API.
- Демонстрационный калькулятор *только* затрат на энергию; значения иллюстративные. Не выдаётся за расчёт стоимости владения или официальную цену.
- Условная SVG-иллюстрация автомобиля. Перед запуском заменить на утверждённое фото АТОМа.
